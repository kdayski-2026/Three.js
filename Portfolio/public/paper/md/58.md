## 0xcoin-4horsmen (soedinyashka)

Сервис для ежедневного анализа рынка BTC и генерации краткосрочного (на 1 день) прогноза на основе:
- криптовалютных новостей;
- анализа твитов;
- результатов работы нейросетевого предиктора по историческим ценам.

Приложение периодически забирает данные из внешнего API, формирует промпт и отправляет его в языковую модель (`ONEAI_API_URL`). Результаты сохраняются в backend через `API_URL` и могут дополнительно рассылаться (например, в Telegram или по другим каналам).

---

### Технологии

- **Node.js** (CommonJS-модули)
- **Docker** (запуск внешних сервисов-предикторов: `predictor`, `twitter`, `manager`)
- **REST API** для обмена с backend:
  - `API_URL` — основной API (новости, предсказания);
  - `ONEAI_API_URL` — API языковой модели.

---

### Основные модули

- `index.js` — основной сервис-планировщик:
  - раз в час проверяет наличие предсказания за текущий день и при необходимости:
    - считает агрегированное настроение новостей;
    - получает текущую цену BTC;
    - запускает Docker-контейнер с ценовым предиктором и читает `result.csv`;
    - запускает Docker-контейнер для анализа твиттера и читает `result.json`;
    - формирует промпт и отправляет его в языковую модель;
    - сохраняет предсказание и по таймеру инициирует его отправку;
  - параллельно раз в час делает краткую аналитическую сводку по свежим новостям.

- `predict.js` — однократный запуск генерации прогноза с отправкой результата (например, в Telegram).

- `modules/news.module.js` — работа с новостями и текущей ценой BTC через `API_URL` и `coindesk`.
- `modules/twitter.module.js` — запуск Docker-контейнера `twitter` и чтение результата из `result.json`.
- `modules/predictor.module.js` — запуск Docker-контейнера `predictor`, чтение `result.csv` / изображения графика, POST/GET запросы для предсказаний.
- `modules/manager.module.js` — запуск Docker-контейнера `manager` для дополнительной обработки данных (использует общие volume-данные).
- `modules/oneai.module.js` — отправка промптов в языковую модель (`ONEAI_API_URL`) и приведение ответа к HTML-формату.
- `api/fetch-api.js` — обёртка над `fetch` для `GET/POST/PUT` запросов.

### Установка и запуск

1. **Клонировать репозиторий и установить зависимости**

```bash
git clone <repo-url>
cd 0xcoin-4horsmen
npm install
```

2. **Создать файл окружения**

На основе `.env.example` создайте файл `.env` и заполните переменные:

- `API_URL` — базовый URL backend-сервиса (новости, предсказания).
- `ONEAI_API_URL` — базовый URL сервиса с языковой моделью.

3. **Подготовить и запустить Docker-сервисы**

В системе должны быть доступны контейнеры:

- `predictor` — прогноз по историческим ценам BTC (используется модулями `predictor.module.js`);
- `twitter` — анализ твитов и расчёт вероятностей падения/роста;
- `manager` — дополнительная обработка результатов (используется опционально).

Скрипты и данные ожидаются по путям:

- `/srv/ai/predictor-ai` — код и данные ценового предиктора (файлы `result.csv`, `img/bitcoin_prediction.png`);
- `/srv/ai/twitter-ai` — код анализа твиттера (`result.json`);
- `/srv/ai/manager` и `/srv/ai/predictor-ai/data`, `/srv/ai/predictor-ai/img` — директории, монтируемые в контейнер `manager`.

4. **Запуск основного сервиса**

```bash
node index.js
```

Сервис будет:
- раз в час проверять, есть ли предсказание на текущий день, и при отсутствии запускать полный цикл аналитики и прогноза;
- раз в час генерировать краткую текстовую аналитику по новостям за последний час.

5. **Одноразовый запуск прогноза**

При необходимости можно запустить разовый прогноз (например, для отладки):

```bash
node predict.js
```

---

### Структура промптов

- **Основной прогноз**: комбинирует агрегированное настроение новостей, текущую цену, прогноз ценовой нейросети и вероятности падения/роста из твиттера. LLM получает строгий шаблон ответа с секциями: «Анализ новостей», «Анализ твиттера», «Анализ графика», «Общий анализ», «Прогноз».
- **Аналитика новостей**: LLM получает новости за последний час и формирует краткий пересказ без повторения заголовков.
