# Tymio

Одностраничный маркетинговый сайт (landing) для продукта **Tymio** — приложений для криптоинвесторов с упором на **доходность в стейблкоинах** и **защиту портфеля** от колебаний цены (лимитные ордера, yield, hedging).

Фронтенд на **React 17** и **Create React App** (`react-scripts` 4): маршрутизация через **React Router v6**, стили — **styled-components** и **Emotion**, формы — **Formik** + **Yup**, часть состояния/событий — **RxJS**. Есть интеграция **Google reCAPTCHA** на страницах с формами.

## Возможности сайта

- **Главная** (`/`) — секции: Hero, Protect, Yield, сценарии использования, безопасность, медиа, FAQ; якорная навигация по блокам (`/:elementId`).
- **White Paper** (`/whitepaper`).
- **Блог** (`/blog`, `/blog/:blog_id`) — статьи с оглавлением и связанными материалами.
- **Условия** (`/terms`).
- **Амбассадоры** (`/ambassadors`) — форма заявки.
- **Клуб** (`/club`) — форма заявки.
- Опциональный режим **Welcome** — отдельная приветственная страница вместо основного лендинга (включается переменной окружения).

Данные для статистики, блога и форм при необходимости запрашиваются с бэкенда по `REACT_APP_API_URL`.

## Требования

- **Node.js** (рекомендуется LTS, совместимый с CRA 4).
- **npm** или **yarn**.

## Установка и запуск

```bash
npm install
```

Скопируйте `.env.example` в `.env` и заполните переменные (см. ниже).

```bash
npm start
```

По умолчанию в `package.json` для `start` задан порт **5112** (через `PORT=5112`). На **Windows** в cmd/PowerShell префикс `PORT=...` может не сработать; тогда задайте порт вручную, например:

```powershell
$env:PORT=5112; npm start
```

или используйте `npm run dev` (порт **5212** в скрипте — та же оговорка для Windows).

Сборка продакшена:

```bash
npm run build
```

Артефакты попадут в каталог `build/`.

## Переменные окружения

| Переменная | Назначение |
|------------|------------|
| `REACT_APP_API_URL` | Базовый URL API (статистика, welcome, клуб, амбассадоры и т.д.) |
| `REACT_APP_APP_LINK` | Ссылка на приложение / store («go to apps» и аналоги) |
| `REACT_APP_CAPTCHA` | Ключ сайта reCAPTCHA для форм |
| `SKIP_PREFLIGHT_CHECK` | Опционально для CRA при конфликтах зависимостей |
| `REACT_APP_WELCOME_PAGE` | При значении `true` показывается Welcome вместо основного Main |
| `REACT_APP_WELCOME_PAGE_DIRECTION` | Настройки направления/контента Welcome (см. код сервисов) |
| `REACT_APP_ABOUT_VIDEO` | ID ролика YouTube для блока Yield |
| `REACT_APP_ABOUT_PROTECT_VIDEO` | ID ролика YouTube для блока Protect |

## Структура проекта (кратко)

- `src/App.js` — маршруты и глобальные модальные окна.
- `src/pages/` — страницы (Main, Welcome, Blog, Club, …).
- `src/components/` — layout, шапка, подвал, UI-кит.
- `src/services/` — запросы к API (статистика, клуб, амбассадоры и др.).
- `src/shared/` — общие утилиты (порталы и т.п.).
