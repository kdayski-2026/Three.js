# robotics-wallets

Небольшой HTTP API на **Node.js + Express** для базовой работы с Ethereum-кошельками через **web3**:

- создание кошелька (генерация адреса/ключа и сохранение приватного ключа на диск)
- получение баланса адреса
- отправка транзакции (подписанная транзакция)
- получение текущих цен газа (через Etherscan Gas Oracle)

> В конфиге по умолчанию указан провайдер **Rinkeby (Infura)** — сеть устарела и сейчас, как правило, недоступна. Для реального использования замените `web3Provider` на актуальную RPC-сеть (например, Sepolia или Mainnet).

## Требования

- Node.js (рекомендуется 16+)
- Доступ к Ethereum JSON-RPC (Infura/Alchemy/свой узел)

## Установка

```bash
npm install
```

## Запуск

```bash
node index.js
```

Сервис стартует на порту из конфига: `PORT` (по умолчанию `3845`).

## Конфигурация

Файл: `config/default.json`

- **`PORT`**: порт HTTP-сервера
- **`web3Provider`**: URL JSON-RPC провайдера Ethereum
- **`gasPriceApi`**: URL Etherscan Gas Oracle API

## API

База: `http://localhost:<PORT>`

### GET `/gas/price/`
Возвращает цены газа в wei:

```json
{
  "slow": "…",
  "average": "…",
  "fast": "…"
}
```

### GET `/wallet/create/`
Создаёт новый аккаунт, добавляет его в web3 wallet и сохраняет приватный ключ в файл:

- директория: `wallets/`
- файл: `wallets/<address>.json`
- содержимое: `{ "privateKey": "0x..." }`

Ответ: объект кошелька (включая `address` и `privateKey`).

### GET `/wallet/balance/?walletAddress=<0x...>`
Возвращает баланс адреса в ETH (строкой), полученный из `web3.eth.getBalance` и преобразованный через `fromWei`.

Пример:

```bash
curl "http://localhost:3845/wallet/balance/?walletAddress=0x0000000000000000000000000000000000000000"
```

### POST `/wallet/transfer/`
Отправляет подписанную транзакцию.

Тело запроса (JSON):

```json
{
  "from": "0x...",
  "to": "0x...",
  "privateKey": "0x...",
  "value": "0.01",
  "gasPrice": "average"
}
```

- **`value`**: сумма в ETH (допускается запятая, будет заменена на точку)
- **`gasPrice`**:
  - число (как строка/число) — будет использовано как есть
  - либо строка: `slow | average | fast` — будет получено из `/gas/price/`
- `gas` фиксирован: `21000`

Ответ: receipt транзакции (как вернёт провайдер).

Пример:

```bash
curl -X POST "http://localhost:3845/wallet/transfer/" ^
  -H "Content-Type: application/json" ^
  -d "{\"from\":\"0x...\",\"to\":\"0x...\",\"privateKey\":\"0x...\",\"value\":\"0.01\",\"gasPrice\":\"fast\"}"
```

## Важные замечания по безопасности

- Приватные ключи сохраняются **в открытом виде** в `wallets/` — не используйте это в продакшене без шифрования/секрет-хранилища.
- Эндпоинт `/wallet/create/` возвращает `privateKey` в ответе — это подходит только для локальной разработки/тестов.
- Ограничьте доступ (firewall/VPN/auth) и не выставляйте сервис в публичный интернет без защиты.

## Структура проекта

- `index.js` — HTTP сервер и реализация эндпоинтов
- `config/default.json` — конфигурация (RPC, API газа, порт)
- `wallets/` — создаётся автоматически, хранит приватные ключи по адресу
