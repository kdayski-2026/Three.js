# Проект: Анализ данных и машинное обучение

Этот проект содержит набор Jupyter Notebook файлов для обработки данных, визуализации и машинного обучения. Ниже приведено описание каждого файла:

## Файлы проекта

1. **date_converter.ipynb**  
   Преобразует даты в CSV файлах в нужный формат.

2. **data_combiner.ipynb**  
   Объединяет данные из разных источников в единый набор данных.

3. **neural_network_example.ipynb**  
   Пример работы с нейронной сетью для решения задачи классификации.

4. **mood_classification.ipynb**  
   Классификация настроения на основе текстовых данных.

5. **mnist_example.ipynb**  
   Пример работы с набором данных MNIST для распознавания рукописных цифр.

6. **news_filter.ipynb**  
   Фильтрация новостей по заданным критериям.

7. **data_filter.ipynb**  
   Фильтрация данных в CSV файлах по заданным параметрам.

8. **model_evaluation.ipynb**  
   Оценка производительности модели машинного обучения.

9. **data_visualization.ipynb**  
   Визуализация данных с использованием различных графиков и диаграмм.

10. **error_analysis.ipynb**  
    Анализ ошибок модели машинного обучения.

11. **model_training.ipynb**  
    Тренировка модели машинного обучения на предоставленных данных.

12. **accident_cost_visualization.ipynb**  
    Визуализация стоимости аварий на основе данных.

13. **random_data_generator.ipynb**  
    Генерация случайных данных для тестирования и анализа.

14. **price_accident_combiner.ipynb**  
    Объединение данных о ценах и авариях для дальнейшего анализа.

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.x и Jupyter Notebook.
2. Клонируйте репозиторий:
   ```bash
   git clone
   ```
3. Перейдите в директорию проекта:
   ```bash
   cd neuroil-parser
   ```
4. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. Откройте нужный файл `.ipynb` и выполните ячейки.
