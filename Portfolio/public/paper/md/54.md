## Backend Helpcenter / ghub-back

Node.js/Express backend‑сервис для интернет‑магазина/каталога товаров. Проект предоставляет REST API для работы с товарами, категориями, корзиной, менеджерами и системными настройками, использует PostgreSQL через Sequelize и поддерживает административную панель.

### Основные возможности
- **Товары и категории**: CRUD‑операции для `Product` и `Category`, список товаров и детальная карточка товара.
- **Каталог**: получение основных данных каталога.
- **Корзина**: просмотр и редактирование корзины (`/cart_list`, `/cart_edit`).
- **Управление менеджерами**: роли, логи и сессии менеджеров.
- **Переводы и поиск**: установка переводов и поиск по данным.
- **Админ‑панель**: авторизация менеджеров и вспомогательные функции админки.

### Технологии
- **Node.js / Express**
- **PostgreSQL** + **Sequelize**
- **axios**, **cors**, **multer**, **nodemailer** и др.

### Подготовка окружения
1. Установить зависимости:
   ```bash
   npm install
   ```
2. Создать файл окружения `.env` (на основе внутренних требований проекта) и задать как минимум:
   ```bash
   PORT=30002
   ```
3. Сконфигурировать подключение к БД:
   - Скопировать `database/config.json.example` в `database/config.json`.
   - Заполнить параметры подключения (`username`, `password`, `database`, `host`, `port`).

### Миграции и сиды БД
- **Создать миграцию**:
  ```bash
  npm run db:make
  ```
- **Применить миграции**:
  ```bash
  npm run db:migrate
  ```
- **Установить целевую миграцию**:
  ```bash
  npm run db:setmigrate
  ```
- **Засидировать данные**:
  ```bash
  npm run db:seed
  ```

### Запуск сервера
- **Обычный запуск**:
  ```bash
  npm start
  ```
- **Режим разработки с `nodemon`**:
  ```bash
  npm run dev
  ```

По умолчанию сервер слушает порт `30002` (или значение из переменной окружения `PORT`), и на корневом маршруте `/` отвечает строкой `API v0.1`.
