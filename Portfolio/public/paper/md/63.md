## MasterGo Client Front

Мобильное приложение на **React Native (Expo)** для клиента сервиса MasterGo.

### Основные технологии

- **Expo / React Native** (`expo`, `react-native`, `expo-router`)
- **Навигация**: `@react-navigation/*`
- **Авторизация и хранение данных**: `jwt-decode`, `@react-native-async-storage/async-storage`
- **Карта и геолокация**: `react-native-maps`, `expo-location`
- **UI-библиотеки**: `react-native-elements`, `react-native-vector-icons`, `react-native-svg`
- **Реальное время и чат**: `socket.io-client`, `rxjs`

### Структура проекта

- `index.js` — точка входа приложения
- `pages/` — экраны приложения (профиль, заказы, платежи, настройки и т.д.)
- `components/` — переиспользуемые UI‑компоненты и виджеты
- `services/` — работа с API бекенда (запросы, авторизация, платежи, чат и др.)
- `hooks/` — кастомные хуки для работы с данными и состоянием
- `shared/` — общие константы, enum'ы и токены
- `lib/` — вспомогательные функции и утилиты

### Требования

- Node.js 18+
- npm или Yarn
- Установленный **Expo CLI**

### Установка и запуск

```bash
git clone <repo-url>
cd mastergo-client-front
npm install
npm run start
```

Для запуска на платформе:

- **Android**: `npm run android`
- **iOS**: `npm run ios`
- **Web**: `npm run web`

### Сборка

Сборка выполняется через **EAS**:

```bash
eas build --profile production --platform android
eas build --profile production --platform ios
```

Профили сборки описаны в `eas.json` (`development`, `preview`, `production`).

### Окружение

Чувствительные данные (URL API, ключи и т.п.) должны задаваться через переменные окружения и подключаться с помощью `react-native-dotenv`. Файл с секретами (`.env`) не должен попадать в git.

# Руководство по сборке APK

1. Установите EAS CLI:  
   `npm install -g eas-cli`  

2. Авторизуйтесь:  
   `eas login`  

3. Билд eas:
   `eas build:configure`

4. Соберите APK:  
   `eas build -p android --profile preview`  

5. Для iOS:  
   `eas build -p ios --profile preview`  

Документация: https://docs.expo.dev/build/setup/, https://docs.expo.dev/build-reference/apk/

# Запуск приложения  
   `npm start`
