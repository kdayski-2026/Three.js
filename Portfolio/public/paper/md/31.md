## Weezi Admin Front

Админ‑панель на базе `react-admin` для управления DAO, пользователями и системными настройками.

### Технологии
- React
- react-admin
- ra-i18n-polyglot + `ra-language-russian` (интерфейс на русском)

### Основной функционал
- Управление DAO (`dao`)
- Управление участниками DAO (`dao_user`)
- Управление пользователями (`user`)
- Управление системными настройками (`system_setting`)
- Управление администраторами и их ролями (`manager`, `manager_role`)

### Запуск проекта
1. Установить зависимости:
   ```bash
   npm install
   ```
2. Запустить dev‑сервер:
   ```bash
   npm start
   ```

Приложение запустится на `http://localhost:3000` (по умолчанию).

### Переменные окружения
- `REACT_APP_TEMPLATE` — шаблон темы (`academy` или `evorich`). По умолчанию используется `academy`.

### Структура
- `src/App.js` — корневой компонент админ‑панели.
- `src/Model/*` — ресурсы `react-admin` (списки, формы редактирования и создания).
- `src/lib/*` — layout, dashboard, провайдеры данных и авторизации, кастомные роуты и темы.
