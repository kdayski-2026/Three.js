## Weezi Admin Back

Node.js/Express backend API на базе Sequelize для административной части проекта Weezi.

### Стек
- **Node.js**
- **Express**
- **Sequelize** (PostgreSQL/SQLite)
- **Jest** для тестов

### Установка
```bash
npm install
```

### Скрипты
- **Запуск в dev-режиме**:

```bash
npm run dev
```

- **Запуск в production-режиме**:

```bash
npm start
```

- **Освобождение порта 30002**:

```bash
npm run killport
```

- **Создание миграции**:

```bash
npm run db:make
```

- **Применение миграций**:

```bash
npm run db:migrate
```

- **Откат последней миграции**:

```bash
npm run db:migrate:down
```

### Переменные окружения
Создайте файл `.env` в корне проекта. Минимальный набор переменных зависит от вашего окружения (БД, порты, ключи и т.д.).

### Структура проекта (общее описание)
- **`index.js`** – точка входа сервера.
- **`database/`** – конфигурация БД, миграции, модели Sequelize.
- **`routes/` / `controllers/`** – роуты и обработчики API (могут отличаться в зависимости от текущей структуры проекта).

### Тесты
Запуск тестов (если используются/реализованы):

```bash
npm test
```
