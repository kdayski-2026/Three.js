# Demolit Logo

## Описание

Интерактивная анимация логотипа компании Demolit с использованием SVG и JavaScript.

## Особенности

- Интерактивное управление анимацией
- Плавные переходы между состояниями
- Адаптивность для различных устройств

## Технологии

- HTML5
- CSS3/SCSS
- JavaScript
- SVG.js

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-repo/Demolit-logo.git
   ```
2. Откройте файл `index.html` в браузере.
