# oneai-back

Backend-сервис для приложения **One AI**: REST API на Express с интеграцией **Google Gemini** (текст и изображения), учётом баланса пользователя в **TON**-стиле (через `bn.js`), хранением данных в **PostgreSQL** через **Sequelize**.

## Возможности

- **Аутентификация** — регистрация и вход, привязка кошелька TON к пользователю.
- **Чаты** — сохранение сообщений, очистка чата, получение истории по пользователю.
- **AI** — ответы на промпты (`gemini-pro`), анализ с PNG (`gemini-pro-vision`) для сценария вроде BTC prediction.
- **Платежи и баланс** — запись платежа по хешу, начисление на баланс; списание за запрос к AI (`GEMINI_PRO_PRICE`).
- **TON Connect** — отдача `tonconnect-manifest.json` для клиента.

## Требования

- Node.js (рекомендуется LTS)
- PostgreSQL

## Установка

```bash
npm install
```

## Конфигурация

1. Скопируйте пример окружения и задайте переменные (в корне проекта файл `.env`):

   | Переменная | Назначение |
   |------------|------------|
   | `PORT` | Порт HTTP-сервера |
   | `API_KEY` | Ключ [Google AI Studio](https://aistudio.google.com/) для Gemini |
   | `GEMINI_PRO_PRICE` | Стоимость одного запроса к модели (строка для BigNumber, в тех же единицах, что баланс в БД) |
   | `DB_ENV` | Окружение Sequelize (по умолчанию `development`) |

2. Создайте `database/config.json` по образцу Sequelize (файл в репозиторий не входит). В нём укажите подключение к PostgreSQL или используйте переменную окружения, если настроите `use_env_variable` в конфиге.

При старте выполняется `connection.sync({ alter: true })` — схема подстраивается под модели (в продакшене обычно используют миграции вместо `alter`).

## Запуск

Разработка с автоперезапуском:

```bash
npm run dev
```

Продакшен (после установки `nodemon` не обязателен):

```bash
node index.js
```

## Основные HTTP-маршруты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/` | Проверка работоспособности |
| `GET` | `/user` | Пользователь по `user_id` |
| `GET` | `/user/balance` | Баланс по `address` кошелька |
| `POST` | `/auth` | Регистрация/логин (`data` в теле) |
| `GET` | `/chat` | Чаты пользователя (`user_id`) |
| `POST` | `/chat/message` | Добавить сообщение в чат |
| `POST` | `/chat/clear` | Очистить чат |
| `POST` | `/prompt` | Запрос к AI со списанием баланса (`user_id`, `chat_id`, `message`, `address`) |
| `POST` | `/message` | Простой запрос к AI без списания |
| `POST` | `/payment` | Зачисление по платежу (`hash`, `address`, `amount`) |
| `POST` | `/btc-prediction` | AI с опциональным PNG в теле (`prompt`, `data`) |
| `GET` | `/tonconnect-manifest.json` | Манифест TON Connect |

Ответы об ошибках — JSON с полем `error`.

## Стек

- **Express**, **cors**, **dotenv**
- **Sequelize**, **pg**
- **@google/generative-ai** (Gemini)
- **bn.js**, **tonweb** — работа с балансами и блокчейном TON

## Структура проекта

- `index.js` — точка входа, маршруты
- `ai.js` — вызовы Gemini
- `lib/` — бизнес-логика: `auth`, `user`, `chat`, `blockchain`, `payment`
- `database/` — подключение Sequelize, модели в `database/models/`

Лицензия указана в `package.json` (`ISC`).
