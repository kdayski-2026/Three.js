## 0xcoin Admin (academy-admin-front)

Админ-панель для управления обучающей платформой и смарт‑контрактными операциями 0xcoin. Проект построен на `React 17` и `react-admin`, использует `MUI`, `styled-components`, `chart.js` и интеграцию с `web3`.

### Возможности
- **Управление пользователями и подписками**: просмотр, фильтрация, редактирование, импорт пользователей и подписок.
- **Курсы и контент**: управление курсами, уроками, тестами и дополнительными материалами.
- **Статистика и аналитика**: дашборды, графики и отчёты по активности пользователей и прогрессу обучения.
- **Реферальные выплаты**: управление реферальными программами и выплатами.
- **Смарт‑контракты и блокчейн**: работа с контрактами через `web3`, мониторинг транзакций и доходов.
- **Локализация**: поддержка нескольких языков (RU, EN и др.) через JSON‑файлы переводов.

### Технологический стек
- **React 17** (`create-react-app`, `react-scripts`)
- **react-admin 3.x**
- **MUI 5** (`@mui/material`, `@mui/icons-material`, `@mui/lab`, `@mui/x-date-pickers`)
- **styled-components**
- **Bootstrap / Reactstrap**
- **chart.js / react-chartjs-2**
- **draft-js / react-draft-wysiwyg** для rich‑text редактора
- **axios** для HTTP‑запросов
- **web3** для взаимодействия со смарт‑контрактами

### Запуск проекта

#### Предварительные требования
- Установленный **Node.js** (рекомендуется LTS версия)
- Пакетный менеджер **npm** или **yarn**

#### Установка зависимостей

```bash
npm install
# или
yarn
```

#### Запуск в режиме разработки

```bash
npm start
# или
yarn start
```

Приложение будет доступно по адресу `http://localhost:3000`.

#### Продакшн-сборка

```bash
npm run build
# или
yarn build
```

Сборка будет сохранена в папку `build/` и готова к деплою на web‑сервер.

### Настройки окружения

- **`.env.example`**: пример файла переменных окружения. Скопируйте его в `.env` и укажите нужные значения (API‑бэкенда, параметры сети, ключи и т.д.).
- **`src/config/network.js`**: конфигурация сетей/эндпоинтов для работы с API и блокчейном.
- **`src/lib/defaultConfig.js`**: базовые настройки админ‑панели.

### Структура проекта (основное)
- **`src/App.js`**: точка входа React‑приложения, конфигурация `react-admin`.
- **`src/lib/`**: провайдеры данных, авторизация, layout, темы, вспомогательные функции.
- **`src/pages/`**: страницы админ‑панели (статистика, выплаты, контент и т.п.).
- **`src/components/`**: переиспользуемые UI‑компоненты и графики.
- **`src/assets/locales/`**: JSON‑файлы локализаций.
- **`src/abi/`**: ABI смарт‑контрактов для работы через `web3`.

### Скрипты npm
- **`npm start`**: запуск dev‑сервера.
- **`npm run build`**: продакшн‑сборка.
- **`npm test`**: запуск тестов.
- **`npm run eject`**: извлечение конфигурации `react-scripts` (необратимая операция).

### Разработка и вклад

- Соблюдайте принятый стиль кода (React + JS, без TypeScript).
- Старайтесь переиспользовать существующие компоненты из `src/lib` и `src/components`.
- Для новых текстов добавляйте ключи в соответствующие файлы переводов в `src/assets/locales/`.
