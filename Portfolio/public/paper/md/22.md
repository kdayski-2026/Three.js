## fsmtp_proxy (enotyBot)

Проект `fsmtp_proxy` — это Node.js‑сервис, который работает как SMTP‑прокси и интегрируется с Telegram‑ботом (через библиотеку `telegraf`). Основная идея — получать/обрабатывать почту и пересылать важные уведомления в Telegram.

### Технологии

- **Node.js**
- **Express** — HTTP‑сервер/REST‑обёртка
- **smtp-server / smtp-connection** — реализация SMTP‑сервера и клиентских подключений
- **nodemailer** — отправка писем
- **mailparser** — разбор входящих писем
- **mongoose** — работа с MongoDB
- **axios** — HTTP‑запросы к внешним сервисам
- **telegraf** — Telegram‑бот
- **winston** — логирование
- **config** — конфигурация через файлы

### Структура проекта

- **`index.js`** — точка входа в приложение.
- **`config/`** — конфигурационные файлы (порты, ключи, параметры подключения и т. д.).
- Другие директории и файлы зависят от конкретной реализации логики бота и SMTP‑прокси.

### Требования

- Node.js (рекомендуется актуальная LTS‑версия)
- Доступ к MongoDB (если используется хранение в БД)
- Данные для подключения к SMTP‑серверу (если требуется пересылка/отправка писем)
- Токен Telegram‑бота

### Установка и запуск

```bash
npm install
node index.js
```

При необходимости добавьте в `package.json` удобные скрипты, например:

```json
"scripts": {
  "start": "node index.js"
}
```

### Конфигурация

Проект использует пакет `config`. Обычно это значит, что настройки находятся в файлах вида:

- `config/default.json`
- `config/production.json`

Там могут задаваться:

- параметры SMTP‑сервера (хост, порт, логин, пароль);
- параметры подключения к MongoDB;
- токен Telegram‑бота и ID чатов/каналов для уведомлений;
- уровень логирования и прочие настройки.

### Идеи по использованию

- Пересылка критичных системных уведомлений на почту → в Telegram.
- Личный «почтовый помощник» в виде Telegram‑бота.
- Логирование и хранение важных писем в MongoDB с быстрым доступом из бота.
