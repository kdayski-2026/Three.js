# uniswap-price

Минимальный HTTP-сервис на **Node.js** и **Express**, который по запросу возвращает ориентировочную цену обмена (индексную цену) для пары токенов через **Uniswap V3** с использованием контрактов **Quoter** / **QuoterV2** (`quoteExactInputSingle`).

Цена считается для фиксированного объёма **1 единицы** базового актива (см. логику в `index.js`): результат округляется до двух знаков после запятой.

## Возможности

- Один эндпоинт `POST /price` с параметрами сети, пары токенов и направления сделки (`buy` / `sell`).
- Поддерживаемые сети (по `chainId`):
  - **1** — Ethereum Mainnet  
  - **42161** — Arbitrum One  
  - **421614** — Arbitrum Sepolia  
  - **8453** — Base  
- Для Base используется **QuoterV2** и иной формат аргументов к контракту; для остальных перечисленных сетей — классический **Quoter**.

## Стек

| Компонент | Назначение |
|-----------|------------|
| `express`, `cors` | HTTP API |
| `ethers` v5 | RPC и вызовы контрактов |
| `@uniswap/sdk`, `@uniswap/sdk-core`, `@uniswap/v3-sdk` | токены, адреса фабрики и вспомогательная логика |
| `dotenv` | переменные окружения |

## Установка и запуск

```bash
npm install
```

Создайте файл `.env` в корне проекта и задайте порт сервера:

```env
PORT=3000
```

Запуск:

```bash
node index.js
```

Для разработки с автоперезапуском:

```bash
npm run dev
```

В репозитории есть скрипт `servestart.sh`, который просто вызывает `node index.js` (удобно на сервере с bash).

## API

**`POST /price`**

Тело запроса (JSON):

| Поле | Тип | Описание |
|------|-----|----------|
| `tokenIn` | string | Символ входного токена (например `ETH`, `USDC`) — должен быть в `TOKEN_ADDRESS` для выбранной сети |
| `tokenOut` | string | Символ выходного токена |
| `chainId` | number | Идентификатор сети (см. список выше) |
| `direction` | string | `"buy"` или `"sell"` — влияет на расчёт индексной цены относительно объёма 1 |

Успешный ответ: `{ "result": { "index_price": <number> } }`.

Ошибка: `{ "error": "<сообщение>" }` со статусом `500`.

## Конфигурация сети

Адреса токенов, RPC-провайдеры, комиссия пула (`500` = 0.05%), адреса Quoter и лимиты цены задаются в `network.js`. При переносе в продакшен рекомендуется вынести RPC URL и секреты в переменные окружения и не хранить ключи в репозитории.

## Структура репозитория

| Файл | Назначение |
|------|------------|
| `index.js` | Express-приложение и маршрут `/price` |
| `uniswap.js` | Quoter, конфиг сделки, получение метаданных токена |
| `network.js` | Константы сетей, токенов и контрактов |
| `lib.js` | Преобразование сырых сумм в читаемый вид |
