## Helpcenter Admin

Панель администратора для управления справочным центром (help center) на базе **React** и **react-admin**.

### Основные возможности

- **Управление статьями**: создание, редактирование, удаление и просмотр записей ресурса `article_crud`.
- **Управление категориями**: создание, редактирование, удаление и просмотр записей ресурса `category_crud`.
- **Авторизация**: кастомный `AuthProvider` с формой входа.
- **Локализация**: поддержка нескольких языков через `i18nProvider` и JSON-файлы переводов в `src/assets/locales`.
- **Кастомная тема и layout**: отдельный файл темы (`themeTymio`) и компоненты `AppBar`, `Sidebar`, `Layout`, `Dashboard`.

### Технологии

- **React 18**
- **react-admin 4**
- **react-router-dom 6**
- **react-pro-sidebar**
- **react-google-recaptcha**

### Требования

- Node.js 18+ (рекомендуется LTS)
- npm или yarn

### Установка

```bash
cd helpcenter-admin
npm install
```

или

```bash
cd helpcenter-admin
yarn
```

### Запуск в режиме разработки

```bash
npm start
```

Приложение по умолчанию поднимается на `http://localhost:3000`.

### Сборка для продакшена

```bash
npm run build
```

Скрипт использует `react-scripts build` и генерирует оптимизированную сборку в папке `build/`.

### Переменные окружения

В репозитории есть пример файла `.env.example`. Скопируйте его в `.env` и при необходимости настройте:

```bash
cp .env.example .env
```

После изменений переменных окружения перезапустите dev‑сервер.

### Структура проекта (кратко)

- `src/App.js` — точка входа админ‑панели `react-admin`.
- `src/providers/` — провайдеры (`AuthProvider`, `DataProvider`, `JsonServerProvider`, `Layout`, `Login`, `Dashboard`, `Routes`, `Translate` и т.д.).
- `src/model/` — описания ресурсов `Article` и `Category` и их формы.
- `src/assets/locales/` — файлы переводов (`en`, `ru`, `es`, `fr`).
- `src/api/` — вспомогательные функции работы с API (`fetch-api.js`).

### Как адаптировать под свой backend

- Обновите `DataProvider`/`JsonServerProvider` в `src/providers/` под свой API (endpoints, схема данных, авторизация).
- При необходимости измените имена ресурсов (`article_crud`, `category_crud`) в `src/App.js` на свои.
- Обновите модели `Article` и `Category` под структуру ваших данных.
