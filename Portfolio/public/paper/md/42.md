# SellBuy Admin

Веб-панель администратора для платформы SellBuy / Academy: интерфейс на базе [React Admin](https://marmelab.com/react-admin/) с CRUD-сущностями, отдельными страницами выплат и смарт-контрактов и многоязычным интерфейсом.

В `package.json` проект указан как `academy-admin-front` (версия 1.0.0).

## Стек

- **React** 17, **Create React App** (`react-scripts` 4)
- **react-admin** 3.x, **Material UI** 5
- **axios**, **socket.io-client**
- **web3** — взаимодействие с блокчейном (выплаты, контракты)
- **i18next** (через настройки react-admin) — локали: EN, RU, ES, IT, HI, VI и др.

## Требования

- **Node.js** (рекомендуется LTS, совместимый с CRA 4)
- **npm** или **yarn**

## Установка

```bash
cd sellbuy-admin
npm install
```

## Переменные окружения

Скопируйте пример и заполните значения:

```bash
cp .env.example .env
```

| Переменная | Назначение |
|------------|------------|
| `REACT_APP_APIURL` | Базовый URL backend API (данные, логин `/login`) |
| `REACT_APP_IMAGEURL` | Базовый URL для изображений и файлов (загрузки, ссылки в редакторе) |
| `REACT_APP_CAPTCHA` | Ключ сайта Google reCAPTCHA для страницы входа |
| `REACT_APP_ENV` | Окружение приложения (используется в части моделей, например заказы) |
| `PORT` | Порт dev-сервера CRA (по умолчанию 3000) |
| `NODE_PATH` | При необходимости — дополнительные пути модулей |

Без корректного `REACT_APP_APIURL` авторизация и загрузка данных работать не будут.

## Команды

| Команда | Описание |
|---------|----------|
| `npm start` | Режим разработки (hot reload) |
| `npm run build` | Production-сборка в каталог `build/` |
| `npm test` | Запуск тестов (Jest / Testing Library) |

После `npm run build` статику можно отдавать любым HTTP-сервером. В репозитории есть примеры скриптов:

- `servestart.dev.sh` — `serve -s build -p 31006`
- `servestart.prod.sh` — `serve -s build -p 30006`

Требуется установленный глобально или локально пакет [`serve`](https://www.npmjs.com/package/serve) (`npx serve -s build -p <порт>`).

## Функциональность

- **Ресурсы react-admin:** пользователи, подписки, доход контракта, реферальные выплаты, заказы, логи.
- **Кастомные маршруты:** выплаты (`/payout`), сроки/экспирация (`/expiration`, `/expirationV3`, `/expiration/info`), смарт-контракт (`/smart_contract`), статистика (`/statistic`).
- Тема оформления: `src/lib/themeSellbuy.js`.
- ABI контрактов: `src/abi/` (ERC20, Payout, PayoutV3).

## Структура (кратко)

- `src/App.js` — корневой `<Admin>` и регистрация ресурсов
- `src/lib/` — провайдеры данных и авторизации, меню, маршруты, тема
- `src/Model/` — списки/редактирование сущностей и общие UI-компоненты форм
- `src/pages/` — отдельные страницы (выплаты, статистика и т.д.)
- `src/assets/locales/` — файлы переводов
