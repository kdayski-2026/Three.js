# tx-catcher (Tymio)

Сервис на Node.js для **аудита обработки смарт-контрактных транзакций** в экосистеме [Tymio](https://tymio.com): он сверяет данные из блокчейна с ответами backend API, ведёт учёт в PostgreSQL, при сбоях шлёт уведомления в Telegram и фиксирует результаты в Google Таблицах.

## Задачи

- Получать список транзакций целевого контракта через API обозревателя блоков (Etherscan-совместимый интерфейс).
- Для каждой новой транзакции: определить метод по `methodId`, загрузить логи через Web3, запросить у API Tymio информацию по хешу.
- Сравнить ожидаемые действия по событиям (справочники `assets/txEvents.js`, `assets/txActions.js`) с тем, что вернул API.
- Сохранять статусы в таблице `Tx` в PostgreSQL; при ошибках дублировать сообщение в Telegram; успешные и проблемные кейсы — в Google Sheet.

Дополнительно в каталоге `service_scripts/` лежат **офлайн-утилиты** для разовой выгрузки событий (например, `NewOrder`) и обогащения их данными из API (`audit/order`).

## Стек

- **Node.js**, **axios**, **web3**, **pg** (PostgreSQL), **dotenv**
- **google-spreadsheet** + **google-auth-library** (запись в таблицы)
- Запуск в режиме разработки: `nodemon` (`npm run dev`)

## Требования

- Node.js (совместимо с зависимостями из `package.json`)
- Доступ к PostgreSQL и созданным таблицам (см. логику в `database/index.js`)
- Ключи API обозревателя и адрес контракта — через `config.json` в корне (файл в `.gitignore`, нужно завести локально по образцу ниже)
- Для Google Sheets: сервисный аккаунт Google в файле `.credentials.json` в корне и переменная `GOOGLE_SHEETS_ID`

## Установка

```bash
npm install
```

Скопируйте `.env.example` в `.env` и заполните переменные. Создайте `config.json` и `database/config.json` (они не коммитятся).

### Пример содержимого `config.json` (структура)

Проект ожидает поля вроде `contract`, `apiUrls`, `apiKeys`, `scans`, `startBlock`, `api` — по цепочкам, задаваемым через `CHAIN_ID`. Точные ключи смотрите в `lib/etherscan.js` и `lib/api.js`.

### Переменные окружения

| Переменная | Назначение |
|------------|------------|
| `CHAIN_ID` | Сеть (например, `1`, `42161`, `8453`) |
| `API_KEY` | Ключ для API Tymio |
| `API_URL` | Базовый URL API (в `.env.example` указан `https://api.tymio.com/api`) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления об ошибках |
| `GOOGLE_SHEETS_ID` | ID документа Google Sheets |
| `DEBUG` | Включить отладочный вывод в консоль |
| `FORCE_TX` | При значении `1` разрешён вызов принудительной обработки транзакции через API (`/tx/force`) |

## Запуск

**Основной цикл аудита** (после настройки БД, конфигов и `.env`):

```bash
node index.js
```

Режим с автоперезапуском:

```bash
npm run dev
```

**Проверка статуса** (заглушка `Auditor.status()`):

```bash
node status.js
```

## Скрипты в `service_scripts/`

Перед запуском задайте `CHAIN_ID` и при необходимости те же `config.json` / API, что и для основного сервиса.

1. **`hashEventExtractor.js`** — для транзакций контракта вытягивает события с заданным именем (по умолчанию `NewOrder`), дописывает их в `service_scripts/<CHAIN_ID>/events.json`.
2. **`dataEnricher.js`** — читает `events.json`, для каждого хеша запрашивает `GET .../audit/order`, сохраняет полные ответы в `enriched/<hash>.json`, а заказы, не найденные в БД, — в `missing/`.

Пример:

```bash
set CHAIN_ID=42161
node service_scripts/hashEventExtractor.js
node service_scripts/dataEnricher.js
```

(В PowerShell: `$env:CHAIN_ID="42161"` перед вызовом `node`.)

## Структура репозитория (кратко)

| Путь | Роль |
|------|------|
| `index.js` | Точка входа, инициализация `Auditor` и запуск цикла |
| `lib/auditor.js` | Логика сравнения БЧ ↔ API и записи в БД / Sheets |
| `lib/etherscan.js` | Список транзакций контракта через explorer API |
| `lib/w3.js` | Логи транзакций через RPC |
| `lib/api.js` | Запросы к backend Tymio |
| `lib/telegram.js` | Отправка ошибок в Telegram |
| `database/` | Подключение к PostgreSQL и операции с таблицей `Tx` |
| `assets/` | Описание методов и событий для сверки |
| `service_scripts/` | Утилиты выгрузки и обогащения событий по хешам |

## Лицензия

Указана в `package.json` как `ISC` (при публикации уточните у владельца репозитория).
