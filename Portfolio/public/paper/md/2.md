# GOST Crypto API

Проект предоставляет API для работы с криптографией на основе ГОСТ.

## Установка и запуск

1. Установите Docker и Docker Compose:
   sudo apt-get install docker-ce docker-ce-cli containerd.io
   sudo curl -L "https://github.com/docker/compose/releases/download/1.27.4/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
   sudo chmod +x /usr/local/bin/docker-compose

2. Установите зависимости:
   npm install

3. Запустите проект:
   docker-compose up

## Основные функции API

- Шифрование: POST /encrypt  
  Параметры: message - текст для шифрования

- Расшифрование: POST /decrypt  
  Параметры: message - зашифрованное сообщение в base64

- Импорт сертификата: POST /import  
  Параметры: cert - zip-файл с сертификатом

- Экспорт сертификата: POST /export  
  Параметры: cert - имя сертификата

## Примеры использования

Шифрование сообщения:
curl -X POST -d "message=Test message" /encrypt

Расшифрование сообщения:
curl -X POST -d "message=base64_encoded_message" /decrypt
