# amazon

Небольшой Node.js/Express сервис для быстрой проверки, есть ли результаты по торговой марке на Justia Trademarks.

## Что делает

- **GET `/`**: отдаёт страницу `index.html`.
- **POST `/trademarks`**: принимает параметр `name`, делает запрос на поиск Justia и возвращает HTML-ответ со ссылкой на поиск и статусом:
  - **`існує`** — если найдены карточки результатов,
  - **`вільний`** — если результатов нет.

Поиск выполняется по адресу `https://trademarks.justia.com/search?q=<name>`, разбор HTML — через `cheerio`.

## Требования

- Node.js (рекомендуется LTS)
- npm

## Установка

```bash
npm install
```

## Запуск

```bash
node app.js
```

Сервис поднимается на порту **3002**.

Откройте в браузере: `http://localhost:3002/`

## Пример запроса

### Через curl

```bash
curl -X POST http://localhost:3002/trademarks ^
  -H "Content-Type: application/x-www-form-urlencoded" ^
  --data "name=apple"
```

Ответ — HTML со ссылкой на Justia и текстом `існує` или `вільний`.
