## VoiceDetector

Приложение для голосового управления компьютером и чтения текста с экрана на русском языке. Использует распознавание речи, эмуляцию нажатий клавиш, Tesseract OCR и синтез речи (RHVoice) для автоматизации действий и озвучивания содержимого.

### Возможности

- **Голосовое управление**: управление плеером (пауза/старт, перемотка вперёд/назад, полноэкранный режим, mute), запуск/закрытие приложений (`Steam`, `Chrome`, CS:GO и т.п.) и переключение между окнами.
- **Работа с играми/приложениями**: автоматизация типовых действий в CS:GO (запуск, свернуть/развернуть, начать поиск и др.) через эмуляцию мыши и клавиатуры.
- **Распознавание текста с экрана**: создание скриншотов, распознавание текста с помощью `Tesseract OCR` и последующее озвучивание.
- **Озвучивание текста**: синтез речи на русском языке через `RHVoice`.
- **Интеграция с VK**: возможность использовать дополнительные функции с помощью `vk_api` (требуется указать свои учётные данные в коде).

### Требования

- **ОС**: Windows.
- **Python**: 3.x.
- Установленные зависимости Python (см. `pip install` ниже).
- Установленный синтезатор речи **RHVoice** (голос Russian Aleksandr).
- Установленный **Tesseract OCR** и добавленный `tesseract.exe` в `PATH`.

### Установка

1. **Клонировать или скачать** репозиторий `voiceDetector` в удобную директорию.
2. **Установить зависимости Python**:
   ```bash
   pip install -r requirements.txt
   ```
   Если файла `requirements.txt` нет, установите пакеты вручную (минимальный набор, ориентируйтесь по `import` в `src/*.py`):
   ```bash
   pip install speechrecognition pyttsx3 pyautogui pyscreenshot opencv-python pytesseract numpy vk_api pywin32
   ```
3. **Установить RHVoice**  
   Установить пакет `RHVoice-voice-Russian-Aleksandr-v4.2.9-setup.exe` (или аналогичный) и убедиться, что голос доступен системе.
4. **Установить Tesseract OCR**  
   Установить `tesseract-ocr-setup-4.00.00dev.exe` (или более свежую версию) и при установке:
   - включить поддержку русского языка;
   - добавить путь к `tesseract.exe` в системную переменную окружения `PATH` (или прописать путь в коде).
5. (Опционально) **VK API**  
   Для использования функций ВК укажите свой логин и пароль в файле кода (см. комментарий около строки с `VkApi(...)` или строкой, упомянутой в старом `dist/readme.txt`). Документацию по `vk_api` можно найти в интернете.

### Запуск

1. Убедитесь, что микрофон подключён и выбран корректный `device_index` в `src/recognize.py` (по умолчанию 1, список доступных устройств можно вывести через `Microphone.list_microphone_names()`).
2. Запустите основной скрипт:
   ```bash
   python -m src.recognize
   ```
   или другой стартовый файл, который вы используете (например, `active.py`/`index.py`, в зависимости от вашей логики запуска).
3. Произнесите голосовую команду (например, «пауза», «старт», «разверни видео», «включи стим», «начни поиск» и т.п.) и убедитесь, что соответствующее действие выполняется.

### Структура проекта

- `src/recognize.py` — основная логика распознавания речи и обработка голосовых команд.
- `src/active.py`, `src/coords.py` — вспомогательные функции для работы с окнами, координатами и автоматизацией действий.
- `src/text_reader.py`, `src/generate.py` — работа с текстом, генерацией/озвучиванием.
- `dist/` — собранные/распространяемые файлы, в том числе старый `readme.txt` с краткой инструкцией.

### Предупреждения и рекомендации

- **Используйте с осторожностью**: приложение может выполнять клики мышью, нажатия клавиш и запускать/закрывать программы. Перед запуском закройте важные документы без сохранённых изменений.
- **Безопасность VK**: не храните логин и пароль от ВК в публичном репозитории. Для личного использования оставляйте их только локально или переходите на токен-авторизацию.
- **Tesseract и распознавание**: качество распознавания текста зависит от качества скриншотов и выбранного языка OCR.
