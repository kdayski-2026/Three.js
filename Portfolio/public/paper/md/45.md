# 0xcoin-back

Backend-приложение для криптопроекта: REST API на Express, WebSocket (Socket.IO), интеграция с блокчейном (Web3), рассылка новостей и уведомлений в Telegram.

## Возможности

- **Аутентификация и пользователи** — регистрация, вход, восстановление пароля, подписки, реферальная программа, UTM, баллы пользователя.
- **Новости и прогнозы** — получение новостей по BTC/ETH через [CryptoNews API](https://cryptonews-api.com/), сохранение в БД, тональность (в т.ч. через Python-скрипты), события для клиента в реальном времени.
- **Админ-панель** — логин, управление пользователями и подписками, контент, статистика активности, реферальные выплаты.
- **Чат и поддержка** — сессии, сообщения через Socket.IO (`/chat`), контакт с поддержкой.
- **Блокчейн** — конфигурация сетей (Ethereum, Arbitrum и тестовые сети в dev), контракты выплат и рефералок, обёртки под Etherscan и токены (см. `config/network.js`, `lib/etherscan.js`).
- **Дополнительно** — амбассадоры, клуб, email через Nodemailer, интеграция с reCAPTCHA.

## Стек

| Компонент | Технология |
|-----------|------------|
| Runtime | Node.js |
| HTTP API | Express 4 |
| БД | PostgreSQL (Sequelize 6) |
| Realtime | Socket.IO 4 |
| Блокчейн | Web3.js |
| Боты / уведомления | Telegraf (Telegram) |
| Почта | Nodemailer |

- Node.js (рекомендуется LTS)

- Python 3 — для сценариев в каталоге `python/` (например, анализ тональности), если вы их используете

## Установка

```bash
cd 0xcoin-back
npm install
```

### База данных

1. Скопируйте `database/config.example.json` в `database/config.json` и укажите параметры подключения к PostgreSQL для нужного окружения (`development` / `production`).
2. При необходимости выполните миграции:

```bash
npm run db:migrate
```

При старте приложения Sequelize выполняет `sync({ alter: true })` — схема подстраивается под модели (для продакшена обычно предпочтительны только миграции).

### Переменные окружения

Создайте файлы `.env.dev` и/или `.env.prod` (скрипты `npm run dev` и `npm run prod` задают путь через `DOTENV_CONFIG_PATH`). Основные переменные:

| Переменная | Назначение |
|------------|------------|
| `PORT` | Порт HTTP API |
| `DB_ENV` | `development` или `production` (влияет на конфиг БД и блокчейна) |
| `NEWS_API_TOKEN` | Токен CryptoNews API для фонового опроса новостей |
| `SOCKET_PORT` | Порт Socket.IO |
| `TELEGRAM_KEY` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID`, `TELEGRAM_SUPPORT_CHAT_ID`, `TELEGRAM_MANAGER_CHAT_ID`, `TELEGRAM_CLUB_CHAT_ID`, `TELEGRAM_CHANNEL_ID` | Чаты/каналы Telegram |
| `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_AUTH_USER`, `EMAIL_AUTH_PASS` | SMTP для писем |
| `RECAPTCHA_SECRET_KEY` | Секретный ключ reCAPTCHA |
| `md5Salt` | Соль для хеширования в auth |
| `REF_FEE` | Параметр реферальных выплат (админ) |

Точный набор зависит от развёрнутых фич; при отсутствии токенов соответствующие части (новости, Telegram, почта) могут не работать.

## Запуск

```bash
# разработка (nodemon + .env.dev)
npm run dev

# продакшен-скрипт (.env.prod)
npm run prod
```

Отладочный режим с расширенным логированием:

```bash
npm run devfan
```

HTTP API монтируется на префикс `/api`. Проверка: `GET /api/` возвращает версию API.

Дополнительно слушается отдельный порт для «secure»-инстанса Express (в коде: `5003` в production, `5004` в development) — не запускайте два экземпляра на одном и том же порту.

## Структура проекта (кратко)

- `index.js` — точка входа, Express, CRUD-маршруты, периодический опрос новостей и Telegram.
- `rotes/router.js` — маршруты API (auth, user, news, admin, chat и др.).
- `controllers/` — обработчики запросов.
- `database/` — Sequelize, модели, миграции.
- `lib/` — бизнес-логика (сессии, чат, email, telegram, web3 и т.д.).
- `config/` — сети блокчейна, сообщения.
- `socket.js` — Socket.IO (новости и чат).
- `python/` — вспомогательные Python-скрипты.
