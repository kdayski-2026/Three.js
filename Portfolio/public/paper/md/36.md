# saft-web

Веб‑клиент (React + TypeScript) для проекта SAFT: UI, роутинг и взаимодействие с backend через JSON‑RPC, а также интеграции с Web3 (кошелёк/сеть).

## Стек

- **React 18**, **TypeScript**
- **react-router-dom**
- **react-app-rewired** (`config-overrides.js`) — полифиллы для Node‑модулей в браузере (crypto/stream/buffer и т.д.)
- **ethers**, **walletconnect**, **web3modal**
- Стили: **Sass**

## Требования

- **Node.js 16** (в Dockerfile используется `node:16.15.1`)
- **npm**

## Быстрый старт

Установка зависимостей:

```bash
npm i
```

Запуск dev-сервера:

```bash
npm run start
```

Сборка:

```bash
npm run build
```

Форматирование:

```bash
npm run pretty
```

## Переменные окружения

Проект использует переменные формата CRA `REACT_APP_*`.

- **`REACT_APP_RPC_API_URL`** — URL JSON‑RPC/API, куда отправляются RPC запросы (см. `src/projects/saft/services/api.service.ts`).
  - В Dockerfile задано значение по умолчанию: `ARG REACT_APP_RPC_API_URL=/api`

Пример `.env.local`:

```env
REACT_APP_RPC_API_URL=http://localhost:8080/api
```

## Роутинг (основные страницы)

Маршруты определены в `src/AppRouter.tsx`:

- `/` — список проектов
- `/:id` — страница аукциона
- `/:id/bids` — управление ставками (вложенный роут)
- `/closed_deals`, `/moderate`, `/rejected`
- `/kyc`, `/broker`
- `/ui` — страница примеров UI‑компонентов (ui-kit)

## Структура проекта (кратко)

- **`src/projects/saft/`** — доменная логика SAFT (страницы, сторы, сервисы, модели)
- **`src/projects/ui-kit/`** — переиспользуемый UI‑kit (компоненты, модели, стили, утилиты)
- **`nginx/`** — конфигурация Nginx для отдачи SPA

## Docker

Сборка образа:

```bash
docker build -t saft-web .
```

Запуск:

```bash
docker run --rm -p 8080:80 saft-web
```

Примечание: `nginx/conf.d/default.conf` настроен на отдачу SPA (fallback на `index.html`) и **не проксирует** `/api`. Если вам нужен прокси на backend, добавьте соответствующий `location /api { proxy_pass ...; }` в nginx-конфиг.

## CI/CD (GitLab)

В `.gitlab-ci.yml` описаны:

- **build**: сборка и публикация Docker-образа в Registry (`latest` и по sha)
- **deploy**: деплой через SSH на сервер и `docker-compose` (переменные окружения берутся из CI)
