# rundec-web

Веб-клиент для **мультиплеерного лобби** с поэтапными игровыми заданиями. Пользователь подключается к комнате по коду, после чего в реальном времени отображаются участники, этапы и сценарии (квиз, покер, мастер, очки, изображение, ожидание и др.).

## Возможности

- **Подключение к комнате** — ввод кода комнаты и ника, валидация формы (Formik + Yup).
- **Опциональный вход через Google** — JWT сохраняется в `localStorage`, используется при работе с бэкендом.
- **Socket.io** — создание/вход в комнату, старт игры администратором, смена этапов и отправка ответов на задания.
- **Экраны по типу этапа** — в лобби подставляются разные компоненты в зависимости от `stage.quest.type` (quiz, poker, master, score, image, wait).
- **Обработка состояний сервиса** — страница технических работ при ответе `503`, страница блокировки IP при `418`.

## Стек

| Технология | Назначение |
|------------|------------|
| React 18 | UI |
| Create React App (`react-scripts` 5) | сборка и dev-сервер |
| React Router 6 | маршруты `/` и `/:room` |
| styled-components | стили |
| socket.io-client 2.x | WebSocket-события |
| RxJS | реактивное состояние конфигурации |
| Formik, Yup | формы и схемы |
| @react-oauth/google | Google Login |

## Требования

- Node.js с npm (или совместимый менеджер пакетов).

## Переменные окружения

Создайте файл `.env` в корне проекта (значения возьмите из настроек вашего бэкенда и Google Cloud Console):

| Переменная | Описание |
|------------|----------|
| `REACT_APP_API_URL` | Базовый URL REST API (используется для `GET /config` и др.) |
| `REACT_APP_CLIEND_ID` | Client ID OAuth 2.0 для Google (имя переменной задано в коде как есть) |

## Установка и запуск

```bash
npm install
npm start
```

По умолчанию dev-сервер поднимается на **порту 10000** (см. `package.json`). На Windows, если префикс `PORT=10000` в скрипте не сработает, задайте порт через `set PORT=10000` (cmd) или `$env:PORT=10000` (PowerShell) перед запуском либо используйте `cross-env`.

Production-сборка (стандартный CRA):

```bash
npx react-scripts build
```

## Структура приложения (кратко)

- `src/pages/MainPage` — главная: код комнаты, ник, подключение, Google Login / выход.
- `src/pages/LobbyPage` — лобби по маршруту `/:room`: список игроков, старт игры для админа, сценарии по типу этапа.
- `src/services` — конфигурация, авторизация, Socket.io, комнаты, диалоги.
- `src/hooks` — `useConfig`, `useAuth`, `useSocket`.
