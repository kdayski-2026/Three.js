## Enoty

Enoty — это веб‑сервис для работы с почтой и подпиской на премиум‑функционал EnotyBot.

### Стек и структура проекта

- **Фронтенд (лендинг)**: статическая страница `index.html` с адаптивной версткой, анимациями и ассетами в папке `assets`.
- **Веб‑приложение**: папка `front/public_html`, приложение на **CodeIgniter PHP**:
  - `application/controllers/Welcome.php` — главная страница.
  - `application/controllers/Subscription.php` — страница премиум‑подписки.
  - `application/views/welcome` и `application/views/subscription` — шаблоны страниц.
  - `application/libraries/Design_lib.php` — библиотека для сборки шаблонов и подключения CSS/JS.
- **Медиа и иллюстрации**: папка `еноти` с SVG‑иллюстрациями персонажей и интерфейса.

### Функциональность

- **Главная страница Enoty**: промо‑лендинг сервиса с описанием возможностей бота.
- **Страница премиум‑подписки**:
  - Отображает ID пользователя (`userId`), переданный в `Subscription::create($userId)`.
  - Показывает состояние премиум‑подписки (активна / отсутствует).
  - Предлагает варианты оплаты (ежемесячно / ежегодно) и оплату банковской картой.
  - Данные о подписке запрашиваются у backend‑API бота по адресу `http://mail.enotybot.ru:4567/user/{userId}`.

### Как запустить проект локально

1. **Клонировать или скопировать проект** в веб‑директорию сервера (например, `htdocs` или `www`).
2. **Настроить виртуальный хост** веб‑сервера (Apache/Nginx), корневой директорией указать:
   - Для лендинга: директорию с `index.html`.
   - Для приложения CodeIgniter: `front/public_html`.
3. **Настроить PHP‑окружение**:
   - PHP версии 7.x или совместимой.
   - Включенные стандартные расширения (json, mbstring и т.п.).
4. **Проверить конфигурацию CodeIgniter**:
   - В файле `application/config/config.php` указать корректный `base_url`.
   - При необходимости настроить маршруты в `application/config/routes.php`.
5. Открыть в браузере:
   - Главную страницу: `http://<домен>/index.html`.
   - Страницу подписки (пример): `http://<домен>/front/public_html/index.php/subscription/create/123456`.

### Зависимости

- **PHP** и веб‑сервер (Apache или Nginx).
- **CodeIgniter** (файлы фреймворка находятся в папке `front/public_html/application` и связанных директориях).
- Внешние JS/CSS‑библиотеки подключаются из локальной папки `assets` и CDN (Bootstrap, jQuery, Font Awesome и др.).

### Примечания по разработке

- Вёрстка лендинга и шаблонов ориентирована на работу с ассетами в `assets/templates/welcome` и `assets/templates/subscription`.
- При изменении структуры CSS/JS рекомендуется обновлять списки файлов в `Design_lib.php`.
- API‑эндпоинт `http://mail.enotybot.ru:4567/user/{userId}` должен быть доступен из среды, где запущен PHP‑сервер, иначе страница подписки будет показывать ошибку.
