# swag-front

Фронтенд-приложение (React) для SWAG: авторизация/подключение кошелька и сценарии голосования/стримов.

## Технологии

- **React 17** + **Create React App** (`react-scripts`)
- **MUI** + **Emotion** + **styled-components**
- **web3 / web3modal / walletconnect**
- **rxjs**, **formik**, **yup**

## Требования

- **Node.js**: рекомендуется LTS
- **npm** (или совместимый менеджер пакетов)

## Быстрый старт

Установка зависимостей:

```bash
npm install
```

Запуск в dev-режиме:

```bash
npm start
```

Сборка production-бандла:

```bash
npm run build
```

Тесты:

```bash
npm test
```

## Конфигурация (переменные окружения)

Проект читает переменные окружения в формате CRA (только с префиксом `REACT_APP_`).

Создайте файл `.env` в корне `swag-front`:

```dotenv
REACT_APP_DEPLOYER_API_URL=https://your-deployer-api.example.com
```

- **`REACT_APP_DEPLOYER_API_URL`**: базовый URL API “deployer”, используется в `src/services/api.service.js` для вызовов `POST {DEPLOYER}/rpc/call`.

## Структура проекта (основное)

- **`src/pages/`**: страницы (`LoginPage`, `MainPage`, `VotingPage`)
- **`src/services/`**: сервисы (API, логин, blockchain, wallet и т.д.)
- **`src/components/`**: UI-компоненты (layout/header/toast/dialog и т.п.)

## Важные примечания

- **Infura ключи сейчас захардкожены** в `src/config/infura.js`. Если репозиторий публичный или ключи чувствительные — лучше вынести их в `.env` и добавить `.env` в `.gitignore`.
