# Excel App (Afina)

Веб-клиент на **React** для работы с табличными данными, загружаемыми с бэкенда через **JSON-RPC**. Интерфейс напоминает Excel: несколько связанных таблиц (задачи, файлы, детали), редактирование ячеек, добавление и удаление строк.

В `package.json` проект назван **afina**; репозиторий/папка — **excel-app**.

## Возможности

- Загрузка представлений таблиц методом `get_table_view` и правка данных через `edit_table_cell`, `add_table_row`, `del_table_row` и связанные RPC-вызовы.
- Главный экран — **TableView**: блоки «Главная», «Файлы», «Подробности» и сводная таблица; таблицы связаны по идентификаторам (`work`, `workTask`, `workTaskAll`, `workTaskFile`).
- Перед работой приложение запрашивает **`/config`** у API; при ответе **503** показывается страница технических работ, при **418** — страница блокировки по IP.
- Состояние сервисов (конфигурация, данные таблиц, Excel) оформлено через **RxJS** (`BehaviorSubject` / `Subject`).

## Стек

| Категория | Технологии |
|-----------|------------|
| UI | React 18, React Router 6 |
| Стили | SCSS Modules, styled-components |

## Требования

- **Node.js** (рекомендуется LTS)
- Доступный бэкенд с JSON-RPC и эндпоинтом конфигурации (см. ниже)

## Переменные окружения

Создайте файл `.env` в корне проекта:

| Переменная | Описание |
|------------|----------|
| `REACT_APP_API_URL` | Базовый URL API (без завершающего слэша), например `https://api.example.com` |

Приложение обращается к `{REACT_APP_API_URL}/config` и отправляет JSON-RPC POST-запросы на тот же базовый URL.

## Установка и запуск

```bash
npm install
```

Скрипты в `package.json` задают порт **20000** и отключают source maps в dev (синтаксис как в Unix):

```bash
npm start
# или
npm run dev
```

**Windows (PowerShell):** если переменная `PORT` не подхватывается, задайте порт явно:

```powershell
$env:PORT=20000; $env:GENERATE_SOURCEMAP="false"; npm start
```

Или используйте [cross-env](https://www.npmjs.com/package/cross-env) для кроссплатформенных скриптов.

## Структура каталогов (кратко)

```
src/
  api/           # JSON-RPC (fetch), константы методов и эндпоинтов
  components/    # Layout, Header, Table, кнопки, диалоги
  hooks/         # useConfig, useAuth, useSocket
  pages/         # TableView, MaintenancePage, IPBlockPage, TableExcel (альтернативный экран)
  services/      # ApiService, TableViewService, ExcelService, ConfigService, SocketService
  helpers/       # перечисления (имена таблиц, статусы)
```

## Сборка production

В `package.json` по умолчанию заданы только `start` / `dev`. Для production-сборки можно добавить скрипт:

```bash
npx react-scripts build
```

Артефакты появятся в папке `build/`.
