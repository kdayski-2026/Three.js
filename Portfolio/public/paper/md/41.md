# Train Game

Проект игры-симулятора поезда на **Unity**. Включает физику состава по сплайну, маршруты, вагоны и локомотивы, UI на **UI Toolkit**, а также поддержку сетевой игры через **Netcode for GameObjects**.

## Требования

| Компонент | Версия |
|-----------|--------|
| Unity Editor | **2022.3.4f1** (LTS) |
| Render Pipeline | **HDRP** (`Assets/Settings/High_PipelineAsset`) |

Рекомендуется открывать проект именно в указанной версии редактора, чтобы совпадали настройки пакетов и импорт ассетов.

## Быстрый старт

1. Установите [Unity Hub](https://unity.com/download) и редактор **2022.3.4f1** с модулями под вашу целевую платформу (например, Windows Standalone).
2. В Hub: **Add** → выберите папку `trainGame` с этим репозиторием.
3. Откройте проект и дождитесь импорта пакетов из `Packages/manifest.json`.
4. Сцена для сборки по умолчанию: **`Assets/Scenes/Multiplayer.unity`** (указана в Build Settings).

Дополнительные сцены для разработки и тестов: `Main`, `Drive`, `Physics`, `MapRoutes`, `Rotes`, `CitySimulation`, `UITest`, `SampleScene`, `AI` — см. папку `Assets/Scenes/`.

## Архитектура (кратко)

- **`Assets/Script/Train/`** — логика поезда: `Train`, `TrainManager`, управление, маршруты (`Route`, `RouteController`).
- **`Assets/Scripts/Train/`** — физика состава: `TrainPhysics` (сплайн, сцепки, тормоза), `TrainCar`.
- **`Assets/Script/Wagon/`** — вагоны, сцепки (`WagonCoupling`), локомотивы.
- **`Assets/UI/`** — интерфейсы на UI Toolkit (спидометр, статус пользователя, экраны магазина и др.).

## Ключевые пакеты Unity

- **Input System** — ввод  
- **Splines** — движение по рельсам / кривым  
- **Cinemachine** — камера  
- **Netcode for GameObjects** + **Multiplayer Tools** + пример **multiplayer.samples.coop** — сеть  
- **AI Navigation** — навигация  
- **ProBuilder**, **Terrain Tools** — уровни и окружение  
- **TextMeshPro**, **UI Toolkit (ugui)** — текст и UI  

Полный список зависимостей — в `Packages/manifest.json`.

## Сборка

**File → Build Settings** — выберите платформу, при необходимости добавьте сцены в список, затем **Build** или **Build And Run**.
