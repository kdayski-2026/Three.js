# Help Center (frontend)

Веб-приложение справочного центра для экосистемы **TYMIO**: просмотр статей, навигация по категориям и разделам, полнотекстовый поиск по базе знаний. Клиент общается с бэкендом по REST API и отображает контент в том числе в формате Markdown.

## Стек

- **React 18** — UI
- **Create React App** (`react-scripts` 5) — сборка и dev-сервер
- **React Router v6** — маршрутизация с префиксом языка (`/:lang/...`)
- **i18next** + **react-i18next** — интернационализация (локали подгружаются через HTTP backend)
- **styled-components** и **Emotion** — стили
- **RxJS** — реактивные сервисы (данные с API)
- **react-markdown** — рендер статей
- **Formik** + **Yup** — формы и валидация (где используются)
- **react-google-recaptcha** — капча (ключ из окружения)

## Основные разделы приложения

| Маршрут | Назначение |
|--------|------------|
| `/:lang` | Главная справки |
| `/:lang/article/:articleId` | Статья |
| `/:lang/categories/:parentId` | Категории |
| `/:lang/sections/:categoryId` | Разделы |
| `/:lang/search/:query` | Поиск |

Корень `/` перенаправляет на `/:lang` с учётом текущего языка из логики приложения.

## Требования

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения:

| Переменная | Описание |
|------------|----------|
| `PORT` | Порт dev-сервера (опционально) |
| `REACT_APP_API_URL` | Базовый URL бэкенда API справки |
| `REACT_APP_WELCOME_PAGE` | URL основного сайта (ссылки в шапке/подвале) |
| `REACT_APP_CAPTCHA` | Ключ Google reCAPTCHA |
| `SKIP_PREFLIGHT_CHECK` | Для CRA при необходимости обойти проверки зависимостей |

Переменные с префиксом `REACT_APP_` встраиваются на этапе сборки.

## Структура `src` (кратко)

- `pages/` — экраны: Main, Article, Categories, Sections, Search
- `components/` — общие UI-компоненты, Layout, Header, Footer
- `services/` — запросы к API (категории, статьи, поиск и т.д.)
- `hooks/` — хуки для данных и поведения
- `helpers/`, `lib/`, `models/` — утилиты и модели
- `public/locales/` — файлы переводов для i18next

## Примечание

В `package.json` имя пакета указано как `tymio` — это историческое имя; репозиторий ориентирован на фронтенд справочного центра (help center).
